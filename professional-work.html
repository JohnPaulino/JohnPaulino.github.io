01

VIDEO / TEST WORKFLOW

Video Search & Segmentation Tool

A GUI-based application designed to make long test recordings easier to review.

The Problem

Long recordings such as test-drive videos can contain hours of footage, making it difficult to manually find the moment when a particular subject or issue was discussed.

The Approach

The program accepts video files, searches the spoken content for a user-specified keyword or phrase, identifies matching moments, and extracts shorter clips surrounding those events.

Python GUI Development Video Processing Speech Processing Automation
02

TEST DATA / FAILURE ANALYSIS

Test Trace Failure Detection Tool

A data-analysis workflow for locating known issues within large test-equipment traces.

The Problem

Large test traces can contain substantial amounts of data, while the event or failure being investigated may occur only during a small portion of the run.

The Approach

The analysis can search for issue-related keywords or detect known signal patterns based on previous failures. Detected events can then be summarized to estimate frequency or the percentage of a run affected.

Python Test Data Signal Analysis Pattern Detection Failure Analysis
03

GEOSPATIAL / VISUALIZATION

GNSS Route Visualization Tool

A lightweight utility for converting raw coordinate traces into visual routes for Google Earth.

The Problem

Raw latitude and longitude logs are useful for processing but difficult to interpret quickly when someone simply wants to understand the path traveled.

The Approach

The utility reads GPS or GNSS coordinate records and generates a KML/KMZ-compatible output that can be opened in Google Earth to visualize and replay the route.

Python GPS / GNSS KML / KMZ Data Transformation Visualization
04

REPORTING / DATA ORGANIZATION

Issue Intake, Parsing & Reporting Tool

An in-development tool for turning loosely formatted issue lists into structured, filterable reports.

The Problem

Issue information can be convenient to enter in a flexible format but difficult to filter, organize, and present consistently afterward.

The Approach

The application parses raw issue entries into separate fields, presents them in a filterable table, and allows users to export a cleaner spreadsheet or report.

Python Data Parsing Filtering Tables Spreadsheet Export
