Video Search & Segmentation Tool

Developed a GUI-based application for reviewing long-form video by searching for spoken keywords and automatically extracting video segments around the detected moments.

The tool is useful for test drives and other long recordings where manually searching through hours of footage would be slow and inefficient.

TRACE

TEST DATA / FAILURE ANALYSIS

Test Trace Failure Detection Tool

Built a workflow for searching test-equipment data traces to identify portions of a run where a known issue may have occurred.

Issues can be located through keywords or through tell-tale signal patterns learned from previous failures and encoded into the analysis logic. The tool can then estimate how often, or what percentage of the run, the issue was present.

Python Data Analysis Signal Detection Failure Analysis Automation
GNSS

GEOSPATIAL / VISUALIZATION

GNSS Route Visualization Tool

Created a small utility that reads GPS or GNSS coordinate data and converts latitude/longitude records into a KMZ/KML-compatible output for Google Earth.

This allows a recorded route to be plotted and visually replayed, turning rows of coordinate data into a much easier-to-understand representation of the path traveled.

Python GPS / GNSS KML / KMZ Data Transformation Visualization
